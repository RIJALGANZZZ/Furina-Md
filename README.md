> **Base script Furina-MD! Created By Tio, Recode & Maintained by RIJALGANZZZ.**

**Furina-MD** adalah base script bot WhatsApp Multi-Device berbasis Node.js yang dirancang agar ringan, responsif, dan mudah dikustomisasi oleh pengembang (*developer*).

---

## 📌 Tentang Proyek

Repositori ini dikembangkan sebagai basis (*base script*) bagi siapa saja yang ingin membuat atau mengkustomisasi bot WhatsApp sendiri dengan struktur kode yang rapi dan fitur-fitur modern.

* **Nama Proyek:** Furina-MD
* **Base Asli:** Tio
* **Recode & Developer:** [RIJALGANZZZ](https://github.com/RIJALGANZZZ)
* **Bahasa Pemrograman:** JavaScript (Node.js)
* **Library WhatsApp:** `@whiskeysockets/baileys` (atau sejenisnya)

---

## ✨ Fitur Utama (Features)

- ⚡ **Multi-Device Support:** Menggunakan koneksi WhatsApp MD terbaru.
- 🛠️ **Easy Customization:** Struktur handler dan command yang sangat ramah untuk pemula.
- 🚀 **Ringan & Cepat:** Konsumsi RAM minimal sehingga stabil dijalankan di RDP, VPS, maupun Panel Pterodactyl.
- 📦 **Modular Code:** Penambahan fitur baru dapat dilakukan dengan cepat tanpa mengganggu sistem utama.

---

## 💻 Persyaratan Sistem (Requirements)

Sebelum menjalankan script **Furina-MD**, pastikan kamu sudah menginstal:
